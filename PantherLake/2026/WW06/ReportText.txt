[MRC]

  Fix VGA initialization timing to occur during MRC training for SOL
  
  [Issue Description]
  VGA SOL initialization was being skipped during cold
  boot when it was intended to occur during Memory Reference Code (MRC)
  training. The VGA initialization was conditionally executed outside
  the MRC training loop, causing the display to not initialize properly
  during memory training when SOL was enabled.
  
  [Resolution]
  1. Moved IGpuVgaInit() call inside the MRC training do-while loop in
     MemoryInitPtl.c so that VGA initialization occurs during cold boot
               ^^^                                                      
     MRC training when enabled.
  
  2. Updated PeiSaPolicyUpdatePreMem.c to add BIT3
     bit to all VgaInitControl settings when SOL is enabled. This ensures
     BIT3 is set to indicate VGA should initialize during MRC training
     rather than during Display Init phase.
  
  3. Removed unnecessary boot mode check (BOOT_WITH_FULL_CONFIGURATION and
     BOOT_WITH_DEFAULT_SETTINGS) as VGA initialization timing should be
     consistent regardless of boot mode.
  
  Package/Module: MemoryInit
  
  [Impacted Platform]
  ALL
